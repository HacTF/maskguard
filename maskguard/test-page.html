真实数据展现形态 · 脱敏能力覆盖矩阵

本页不是「照着插件能力摆出来的靶子」。它按市面上真实系统渲染敏感数据的方式分区：中后台组件、Canvas 在线表格、图表、PDF、富文本、Shadow DOM、iframe、属性承载、框架重渲染等。每个形态都标注了预期结果（应遮盖 / 应保持原样 / 结构性不可达），页面自检每 1.5 秒比对实测值，把「不符合预期」的形态单独列出来。所有测试数据均为虚构。

二、矩阵总览与判定口径

「应保持原样」同样是合格结果 —— 测试的是行为是否符合预期，不是遮盖数量

分组形态预期判定依据
A · DOM 文本详情页 / 表格 / 列表 / 气泡 / 日志 / JSON 树 / 弹窗 / 附件名 / 富文本应遮盖文本节点被替换，原文整串不再出现在 textContent
业务系统已掩码、超长文本、noscript / template / JSON-LD、可编辑区保持原样按设计不命中或主动跳过，textContent 仍含原文
跨标签拆分、Shadow DOM（open root）应遮盖v1.1 增强：跨节点拼接匹配 + 递归遍历 shadow root；关闭对应开关后应保持原样
SVG 图表标签保持原样默认跳过 SVG 以免破坏图表；开启高级页「SVG 文字」后应变为遮盖
同源 iframe（srcdoc / about:blank）应遮盖all_frames=true + match_about_blank=true 应注入子帧；实测不符即为缺陷
B · 非文本载体input.value / textarea / select、data-* / href / src、JS 内存、导出文件、剪贴板结构性不可达坚决不改：改了会破坏表单提交、导航与业务逻辑。需后端脱敏 / 网络层拦截
placeholder / title / alt / aria-label、document.title、CSS 伪元素、Canvas、图片内文字默认不可达前两类可在高级页开启「属性 / 标题遮盖」；Canvas 与图片请用位置规则 + 视觉模糊算法整块遮盖
C · 时序行为AJAX 延迟渲染、SPA 刷新、框架受控重渲染、轮询、骨架屏替换、200 行批量插入、无限滚动应遮盖点按钮触发后，600ms 内探针文字应被替换
D · 手动指定位置规则 / 框选 / 右键 / 选中文本按配置只遮指定容器，字段名与相邻区域不受影响

探针机制：每个形态自带 data-raw（原文，存在属性里不会被改）与 data-probe（读取用户实际能看到/读到的值的函数）。自检比对两者，再与 data-expect 比对。说明区、矩阵表、按钮、代码一律标 data-mg-skip，避免自身被遮导致误判。

四、B 组 · 非文本节点载体（结构性不可达）

默认配置下探针验证这些值确实未被改动；带开关的项可在高级页开启后重测，Canvas / 图片请用「视觉模糊」位置规则

B01表单 value / textarea / select不可达所有业务系统
值是属性 / 表单状态，不是文本节点；改了还会破坏提交。需后端或业务侧掩码。—
B02属性承载：placeholder / title / alt / aria-label / data-*不可达ARIA / session replay 采集清单
↑ hover / 读屏 / DevTools 均能看到原文；插件只改文本节点。

B03CSS 伪元素 content: attr()不可达CSS generated content
徽标渲染的号码 →

B04Canvas 在线表格单元格不可达腾讯文档 / 飞书表格 / Sheets / S2 / Luckysheet
文字由 fillText 绘制成像素，页面里没有任何文本节点。启用 test-config.json 的 test_blur_canvas 位置规则可整块模糊。—
B05Canvas 图表标签 / 大屏不可达ECharts Canvas 渲染器

B06图片 / 扫描件 / 截图内的文字不可达身份证扫描件 / 附件预览
↑ 文字绘制在图片像素里，DOM 中不存在该文本节点

B07页面标题 / 地址栏 query不可达document.title / URL
标签页标题：CRM-13800138000　·　URL：?phone=13800138000
浏览器 UI 与 URL 不在页面 DOM 内，插件无法修改。—
B08JS 内存 / 网络响应 / console不可达React state / Vuex / fetch 响应
模拟 window.__rawResponse = { phone: "13800138000" }；DevTools Network / Console 里仍是原文。
本插件只改显示层，不拦截请求、不清理内存变量；导出/接口侧需后端脱敏。—
B09下载导出文件 / 剪贴板部分可达CSV / Excel 导出

B10无障碍树 / 读屏器文本不可达aria-label / aria-valuetext
