检测行为
真实页面形态覆盖

默认只处理 DOM 文本节点。上面几项按需开启；input.value、data-*、href/src 一律不改（会破坏表单提交与导航）。Canvas 在线表格、图片内文字、网络响应、下载文件没有文本节点，请用「指定位置」规则配合视觉模糊算法整块遮盖。

拼接识别的边界：只在同一段文字被拆开时生效——拼接长度 ≤ 40 字符、命中需覆盖该段 70% 以上、遇到块级元素即截断、数字串两侧还有数字则不视为一个值。表格里并排的多个字段因此不会被误并成一条（否则整行会塌进第一格）。

配置管理

「插入演示数据」会在当前页面右上角临时写入手机号 / 证件号 / 卡号 / 邮箱，用于验证自动识别与动态内容监听，15 秒后自动移除。「临时还原」只在当前页面生效，页面刷新或产生内容变化后会按规则重新遮盖。

安装（Edge / Chrome）

  1. 地址栏输入 edge://extensions（Chrome 为 chrome://extensions）。
  2. 打开「开发人员模式」，点「加载解压缩的扩展」，选择本插件目录（含 manifest.json）。
  3. 固定到工具栏，点图标打开配置面板。
  4. 若要在本地 file:// 页面生效，需在扩展详情页开启「允许访问文件网址」。

自动识别

内置身份证、银行卡、手机号、邮箱、IP 规则。在「规则」页新增自定义正则，选择遮盖算法即可。支持 g / i / m / s 标志，可在表单里输入样例文本实时预览结果。

手动指定位置

  • 框选：点「框选页面位置」，在目标页面移动鼠标并单击元素，自动生成稳定的 CSS 选择器规则。Esc 取消。
  • 右键：选中一段文字右键「脱敏选中的文本」（仅当前页面生效，原文不写入本地存储）；或在任意位置右键「将此位置加入脱敏」。
  • 位置规则可在规则列表里编辑，改用其它遮盖算法或调整选择器。

快速验证

打开任意普通网页 → 「高级」→「插入演示数据」，右上角会出现一段含手机号、证件号、卡号、邮箱的文本，应被自动遮盖；按住 Alt 可查看原文。该演示块 15 秒后自动移除。

其它

  • 按住 Alt 临时查看原文，松开恢复遮盖。
  • 遮盖算法：全部遮盖 / 部分保留 / 固定长度 / 标签替换 / 哈希摘要 / 保格式打乱 / 自定义替换。
  • 遮盖符可用 * █ ● 或自定义字符；█ 为黑条视觉遮盖。
  • 输入框、脚本、代码块、可编辑区域默认跳过，可在「高级 → 跳过区域」调整。
  • 仅改当前页面的显示文本，不上传、不修改服务器数据。
  • 安全策略默认拦截嵌套量词 / 交替分组等高回溯正则，并限制单文本节点字符数；确需放行可在「高级」勾选，但可能卡死页面。
  • 规则上限 100 条；html / body / * 等整页选择器会被拒绝，避免误遮盖整页。
